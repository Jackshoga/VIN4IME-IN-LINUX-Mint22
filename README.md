# VIN4IME-IN-LINUX-Mint22
VIN4 輸入法LINUX版(Mint 22)
A traditional Chinese input Method for LINUX Mint 22. This is a installer with many useful function
在LINUX 的XFCE版(Ubuntu 24.04 系（Mint 22.x、Pop!_OS 24.04 等）)的CLI終端機下,執行:

sudo dpkg -i vin4ime_*.deb

sudo apt -f install   # 如果缺 fcitx5 相依套件,用這個補齊

fcitx5 -r -d &         # 重啟 fcitx5,再用 fcitx5-configtool 加入「維音」

fcitx5-configtool
